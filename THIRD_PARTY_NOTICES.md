# Provider icons

The bundled YouTube, Wikipedia, Reddit, Google, Google Translate, IMDb, and Amazon SVG icons come from [Simple Icons](https://github.com/simple-icons/simple-icons), whose icon collection is distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Amazon uses release 12.4.0; the other icons were retrieved from the develop branch on November 2, 2026. Brand names and marks belong to their respective owners.

Provider chip layout takes visual inspiration from [Crest](https://github.com/pauljoda/Crest); no Crest source code or artwork is included.
